# 응답 저장(구글 시트) 연결 방법

학교(또는 담당 선생님) 구글 계정으로 진행하세요. 데이터가 그 계정 소유가 됩니다.

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: `같은 캠퍼스 응답`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. 저장소의 `config.js`에서 `endpoint: ""` 안에 붙여넣고 커밋합니다.

수집 항목은 익명 응답(들은 질문, 선택한 답, 소감, 체크 항목)뿐이며 이름·연락처는 받지 않습니다.
